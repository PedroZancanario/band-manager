# Band Manager

A web application for managing music bands. Users can register, search, edit, and delete bands while keeping their data saved in the browser.

## Features

* Register new bands
* View registered bands
* Search bands by name
* Edit band information
* Delete bands
* Persist data using Local Storage
* Form validation
* Responsive interface

## Technologies

* HTML5
* CSS3
* JavaScript
* Local Storage
* Git
* GitHub

## How to Run

1. Clone the repository:

```bash
git clone git@github.com:PedroZancanario/band-manager.git
```

2. Enter the project directory:

```bash
cd band-manager
```

3. Open `index.html` in your browser.

No additional dependencies are required.
